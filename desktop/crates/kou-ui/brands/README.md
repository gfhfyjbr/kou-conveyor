# Marks of the products the app runs

`claude`, `openai`, `googlegemini`, `opencode`, `cursor`, `githubcopilot` and
`qwen` are taken unchanged from [Simple Icons](https://simpleicons.org) 16.37.0,
which publishes them under CC0-1.0. The marks are their owners' trademarks;
the app shows them only to say which product runs in a pane.

A harness that has no mark there (Amp, Droid, Pi, Aider, Goose, Kiro, Grok,
Devin) keeps its two letters. Simple Icons' `amp` is a different product and
is not used. To add one, put its SVG here (one path, a 24 by 24 view box) and
name it in `src/brands.rs`.
